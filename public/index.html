🔥 Platform Setup — Deployer Only
This screen is for whoever is deploying this SaaS, one time. Individual companies never see this — they just Register.
⚠️ One Firebase project serves every company. Companies are isolated by security rules, not by separate projects — do not create a new Firebase project per customer.
1
Create ONE Firebase Project
Go to console.firebase.google.com → Add Project → name it after your SaaS platform → Create Project
2
Add Web App + Copy Config
⚙️ Project Settings → Your Apps → </> Web → Register app → copy the firebaseConfig values below
3
Enable Firestore + Deploy Security Rules
Build → Firestore Database → Create Database → Production Mode → then deploy the firestore.rules file provided with this app (do not leave it in Test Mode)
4
Enable Authentication
Build → Authentication → Get Started → Enable Email/Password
5
Bake this config into the source once
Paste values below for local testing, or hardcode them into SAAS_FIREBASE_CONFIG in the source before you deploy so customers never see this screen
